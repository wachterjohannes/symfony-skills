# OpenCode

OpenCode reads `AGENTS.md` from the project root, so the setup matches Codex.

## Install

```bash
mkdir -p .agents
cp -R /path/to/symfony-skills/skills .agents/skills
```

Copy the table from this repository's `AGENTS.md` into your project's `AGENTS.md` and
adjust the paths.

## Updating

Copy the folders again and check the table for missing rows.

## Removing

Delete the folders and the table.
